# SpeechMate — Linguistic Data Sources & Validation

## Overview

SpeechMate's linguistic datasets represent a curated compilation of endangered language vocabulary for **Car Nicobarese** and **Great Andamanese**, sourced from published academic materials and government linguistic surveys.

All data is stored locally on-device and governed by a strict [CC BY-NC 4.0 + TK protocol](../DATA_TERMS.txt).
