## What This Dataset Contains

This directory contains structured linguistic data for **Nicobarese** and **Great Andamanese** — two indigenous languages of the Andaman and Nicobar Islands, India. The dataset includes:

- Vocabulary entries (English ↔ Nicobarese, English ↔ Great Andamanese)
- Dialectal variants and phrase collections
- Cultural context notes

The data was compiled by the **SpeechMate project** (github.com/sathiyatskrj/Speechmate) through community-supported documentation work with Nicobarese-speaking members of the Andaman and Nicobar Islands. It represents original compilation work and carries copyright from the date of first assembly (December 2025).
